# ProjectTimer

This project is made with Codex by Chatgpt.

its a personal project for my raspberry pi. but if you somehow found out about this project

this shows a clock. its for 480x1920 small IPS screen i have.

Codex made me a nice editor with small animations 

if you want to test it out. you need python

to open it simply open the luncher.py and it should auto open the localhost. 

the main html is app.html. there is app-pi.html for pi usage.

there is a sh file in the runtime file but hasn't been tested yet

Themes now can be selected by a drop down menu.
after that you have a selection of themes. themes can be found in the themes branch, to set them you need to type "set <theme>" and then you reload the runtime 
For anyone wanting to use it. the themes should have layout.json, theme.json. style.css is not needed (i think, i didn't test that) sometimes it gets pissy about not thing a background png so give it a bg.png in assets folder but it maybe can be changed in theme.json. 

few things i recommend to downland layout.json when making a theme since it dosen't have autosave.
